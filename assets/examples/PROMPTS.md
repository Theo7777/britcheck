# Generation prompts

The exact prompts used to produce the example set, and the model each went to.
The failure images were generated by deliberately naming the American element in the
prompt. A test has to be reproducible. They show what britcheck catches, not how often
models get it wrong.

Every prompt ends with the same suffix: `Documentary photograph, 35mm, natural light, realistic, not stylised.`
